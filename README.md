# Coffee Shop Sales Analysis - SQL

## Project Overview

This project analyzes coffee shop sales data using SQL to identify revenue trends, store performance, product performance, and peak sales periods.

## Tools Used

- PostgreSQL
- pgAdmin 4
- SQL
- GitHub

## Dataset

The dataset contains coffee shop transactions, including transaction date, transaction time, store location, product category, unit price, and quantity sold.

## Business Questions

- Which store generates the highest revenue?
- Which products generate the most sales?
- What are the peak sales hours?
- How does revenue evolve by month?
- Which product categories perform best?

## SQL Skills Demonstrated

- SELECT
- GROUP BY
- ORDER BY
- Aggregations
- Date functions
- Revenue calculations
- Business analysis
